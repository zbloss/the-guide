Background: Currently The Guide takes the DnD rules and the campaign and allows you to interact with it over natural language. This is very powerful for DMs. Now we need to add some structure to the story to help new DMs. DnD is a very loose game which is fun at times, but for new DMs or even experienced DMs running complicated campaigns, it can be hard to keep track of everything. When a campaign document is ingested, we need to turn that into a structured story with definitive events, subplots, and character arcs. We currently extract all text from documents and upload them to qdrant for semantic search. We need to modify this process to structure the campaign into a structured story. Instead of waiting for the DM to use our app to generate an encounter, we will prepopulate those encounters. I'm guessing this will require significant rework of the backend, and of course we will need to update the frontend to support this new functionality, but it will be worth it in the end.

Tasks:
1. Refocus The Guide to be specifically for Dungeon Masters. We will no longer cater features to players.
2. Rework our ingestion process so we are no longer handling and storing the DnD Dungeon Master Guide, Monster Manual, System Reference Document, and the Campaign documentation the same way.
    1. Each of these documents should be handled specifically and differently as they serve different use cases.
    2. The Dungeon Master Guide is a document to reference when the DM has a question about how to play DnD or for nuances about the game, but not the campaign.
    3. The Monster Manual provides details about different monsters.
    4. The DnD System Reference Document (SRD) provides specifics about monster stats like their health, how much damage they do with each attack, etc. It also provides pricing information for various items. Think of this document as a heavily utilized index.
    5. Campaign specific documentation is the most important document. It contains the story, the world, the characters, the quests, etc. This is what we need to turn into a structured story.
    6. The Dungeon Master Guide, Monster Manual, and SRD are global documents that do not change between campaigns. In an ideal world, we would parse each of these documents once and organize their data into a relational database that would be reused across all campaigns.
    7. The Campaign document(s) will vary from campaign to campaign and tell the story that we need to structure.
3. Crawl over the Campaign document and generate a structured storyline complete with major and minor events, encounters, plots, and character development points.
    1. The DM will need an admin page that allows them to view the structured story and edit it as they see fit.
    2. The AI Agents will need access to all edits made by the DM to ensure consistency throughout the story.
4. Rebuild the frontend UX so that the DMs core function is to view the structured story and interact with it by filling in details and notes, along with facilitating battle and dialogue.
    1. Much of the functionality we have currently in The Guide should be repurposed and re-integrated into this new UX once we have a structured story for each campaign. For example, the Session Recap button can now see exactly where we progress the story last and summarize that session. The Story So Far button can see exactly how far into the campaign we have progressed, and the Story to come can see what we have left to do.
5. Create a more robust Campaign Creation process that allows the DM to select which global documents to use for that campaign (by default will use the 2024 DM Guide, Monster Manual and SRD) and allows the DM to upload the core campaign document as well as any supplemental documents, along with a brief description of what those supplemlemental documents are good for. This campaign creation process should also be where characters are added, be sure to utilize our new character sheet upload functionality.
6. For any OCR or text extraction tasks from PDFs, first convert each page of the PDF into an image and then send that image to the GUIDE__OLLAMA_BASE_URL using the GUIDE__OCR_MODEL with the prompt "Text Recognition: " followed by the image. 

Goal: Update The Guide to turn DnD Campaigns into structured stories that have definitive events, subplots, and character arcs.
